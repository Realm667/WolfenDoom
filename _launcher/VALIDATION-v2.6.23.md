# Launcher 2.6.23: campaign options

Use an unmodified UZDoom 5.0.3 configuration. In single-player, toggle Debug mode:
the Keen mission for the selected episode should appear and disappear. Disabling
debug with a Keen map selected must restore the normal episode start. The co-op
mission selector must never gain Keen maps. Older game packages without the five
level-restart skills must not offer the third death rule.
